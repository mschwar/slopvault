- Nothing (and I mean nothing) handles the full spectrum: AI novels, Suno tracks, research papers, structured databases, and images all in one clean profile. Arxiv is too academic, Medium too bloggy, DeviantArt too human-art focused (and anti-AI vibes are still real).

**Gap = massive.** We're the "GitHub + Arxiv + Pinterest + Reddit" for anything an AI can spit out. That's the moat.

### MVP – Keep it stupid simple, ship in weeks

Core loop:

1. Drag-and-drop upload (or paste text/link)
2. Auto-pull metadata (prompt, model, seed, date, category tags you pick or we suggest)
3. One-click "Public" or "Private"
4. Your profile = beautiful personal gallery + "My Creations" vault (like a personal Arxiv + DeviantArt gallery)

That's it. No feed yet. No messaging. Just **save it forever** and **show it off** with a clean URL (yourname.site/slug).

Tech note: Use something like Supabase + S3 + basic tagging. Embeddings for future similarity search (find "similar vibe to this image I made"). We can add version history later (v1, v2, remix) like Git.

- Auto-categorize: Art / Writing / Music / Video / Research / Data / Wildcard
- Prompt search across the entire site (people will go feral for "show me every cyberpunk cityscape made with Flux last week")

**Phase 3 – Sticky as hell**

- Challenges/expos ("AI Novel March Madness", "30-day Song-a-Day") like NightCafe but for everything

### Risks we actually need to think about

- Slop flood: Embrace it. Sorting by "Top" vs "New" + user blocks + optional quality filters solves 80%.

- Legal: Crystal-clear "you own your generations" terms. We're not training on uploads unless users opt in (big future upside).
