# Google Corpus

Use this directory for Google-origin raw material used to develop ingestion support.

## Important Note

This is currently the messiest provider bucket in the repo.
It should be treated as a mixed holding area, not as a normalized source tree.

## Likely Export / Capture Methods

- Gemini web copy-paste
- Gemini AI Studio output
- Google Takeout or activity exports
- other Google-origin artifacts that may later need to be split out

## Current Expectation

Do not assume every file here belongs to the same ingestion strategy.
If you add structure, prefer subdirectories or sidecar manifests that clarify export method without rewriting the raw files.
